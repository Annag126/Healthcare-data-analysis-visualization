# Healthcare-data-analysis-visualization
Exploratory Data Analysis and visualization of healthcare data using Python.
Project Overview

This project explores a healthcare dataset using Python to understand patterns and relationships between health-related measurements and diabetes outcomes.

Objectives

Clean the dataset and handle invalid or missing values.

Perform statistical analysis and exploratory data analysis (EDA).

Visualize distributions and relationships using charts.

Analyze correlations between variables and diabetes outcomes.

Summarize key findings from the analysis.

Tools & Technologies

Python

Pandas and NumPy

Matplotlib and Seaborn

Jupyter Notebook

Dataset

The project uses the Pima Indians Diabetes dataset, which contains health-related measurements and an Outcome column indicating diabetes status.

Key Findings

Glucose had the strongest positive correlation with the outcome among the variables analyzed.

BMI and age also showed positive correlations with the outcome.

Correlation indicates association, not causation.

Project Files

Statistics_DV_EDA.ipynb — data cleaning, statistical analysis, visualizations, and findings.

diabetes.csv — dataset used for the analysis.

requirements.txt — Python libraries required to run the project.

How to Run

Download or clone this repository.

Install the required libraries using pip install -r requirements.txt.

Open Statistics_DV_EDA.ipynb in Jupyter Notebook.

Run the notebook cells in order.

Note: This project is for educational and analytical purposes only and is not intended for medical diagnosis.
